# 복도 끝의 그녀

> 새벽 두 시, 폐교의 복도. 누군가 너를 쫓고 있다.  
> 잡히면 죽는다. — 단, 조건을 갖추고 있다면.

쯔꾸르(RPG Maker) 감성의 **추격 × 미연시** 웹게임입니다.
HTML / CSS / JavaScript 만으로 만들어졌고, 빌드 없이 `index.html` 을 열면 바로 실행됩니다.

## 실행 방법

```
index.html 더블 클릭 (또는 브라우저로 드래그)
```

별도 서버, 설치, 인터넷 연결이 필요 없습니다.

## 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` / 방향키 | 이동 |
| `Shift` | 달리기 (체력 소모) |
| `Space` / `Enter` / 클릭 | 대화 진행 · 선택 |
| `1` ~ `4` | 선택지 고르기 |
| `M` | 음소거 |

## 게임 규칙

1. 복도에서 그녀에게 **잡히면 원래는 즉사**합니다.
2. 하지만 아래 두 조건을 **동시에** 만족한 상태로 잡히면, 그녀가 말을 겁니다.
   - 🧸 **소울 인형 소지** (복도 어딘가에 있음)
   - 🕯 **촛불 점등** (연료가 남아 있을 것 — 복도의 촛대에서 보충)
3. 대화에서 선택지로 **호감도**를 쌓으세요. 대화는 전부 4라운드.
4. 4라운드에서 **호감도 55 이상**이면, 함께 탈출하는 진엔딩에 도전할 수 있습니다.

### 팁

- ✦ **기억의 파편**을 주우면 호감도 +3. 매 라운드 3개씩 새로 생깁니다.
- 촛불 연료는 계속 줄어듭니다. 촛대 근처에 가면 자동으로 다시 밝혀집니다.
- 라운드가 오를수록 그녀의 추격 속도가 빨라집니다.
- 대화에서 **편지**를 갖고 있으면 특별한 선택지가 열립니다.

## 엔딩

| 엔딩 | 조건 |
|---|---|
| TRUE END — 빛의 복도 | 4라운드에서 호감도 55 이상 + 「같이 나가자」 |
| END 2 — 혼자의 아침 | 4라운드에서 「나 혼자 갈게」 |
| END 3 — 남겨진 자 | 4라운드에서 「네가 나가」 |
| END 4 — 다시, 복도 | 4라운드에서 침묵 |
| BAD END — 사냥 | 4라운드 진입 시 호감도 15 미만 |
| YOU DIED | 조건 없이 잡힘 |

## 파일 구성

```
index.html   화면 구조 (HUD · 대화창 · 타이틀/엔딩 화면)
style.css    쯔꾸르풍 UI, 다크 호러 톤
game.js      게임 루프 · 맵 · 추격 AI(BFS) · 조명 · 대화 엔진 · 사운드
```

- 맵은 30 × 17 타일(32px) 텍스트 맵입니다. `game.js` 의 `MAP_SRC` 를 고치면 바로 반영됩니다.
- 추격 AI는 그리드 BFS 로 최단 경로를 0.24초마다 다시 계산합니다.
- 조명은 별도 캔버스에 `destination-out` 마스크를 그려 구현했습니다.
- 사운드는 WebAudio 로 실시간 합성합니다 (오디오 파일 없음).
